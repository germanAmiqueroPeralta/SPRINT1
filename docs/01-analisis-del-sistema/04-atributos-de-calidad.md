# Atributos de calidad

| ID | Atributo de calidad | Escenario de calidad |
|---|---|---|
| AC01 | **Seguridad** | Los datos personales y de salud de los niños solo deben ser accesibles por usuarios autenticados con el permiso adecuado. Un padre solo puede ver a sus propios hijos. |
| AC02 | **Trazabilidad (auditabilidad)** | Todo cambio sobre los datos debe quedar registrado con el usuario, el dispositivo, la IP, la fecha y los valores anteriores y nuevos. |
| AC03 | **Integridad de datos** | El sistema no debe aceptar información inconsistente, por ejemplo controles con fechas anteriores al nacimiento o más de 5 evidencias por reclamo. |
| AC04 | **Mantenibilidad** | El sistema debe permitir cambiar una regla de negocio o una tecnología (base de datos, almacenamiento de archivos) sin afectar otros módulos. |
| AC05 | **Usabilidad** | El portal familiar debe ser simple para padres sin experiencia técnica y usable desde el celular. |
| AC06 | **Disponibilidad** | El sistema debe estar disponible en el horario de atención de los establecimientos de salud. |

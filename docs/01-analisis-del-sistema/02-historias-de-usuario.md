# Historias de usuario

| ID | Historia de usuario | Actor |
|---|---|---|
| HU01 | Como personal de salud, quiero registrar a un niño con sus datos de padrón y su establecimiento, para poder hacerle seguimiento. | Personal de salud |
| HU02 | Como personal de salud, quiero registrar a los padres o apoderados y vincularlos con sus hijos, para saber a quién contactar y darles acceso al portal. | Personal de salud |
| HU03 | Como personal de salud, quiero registrar los controles CRED de cada niño según su edad, para llevar el control de las prestaciones realizadas y pendientes. | Personal de salud |
| HU04 | Como administrador, quiero gestionar el catálogo de paquetes y prestaciones por edad, para que los controles sigan la norma vigente. | Administrador |
| HU05 | Como administrador, quiero gestionar micro redes, establecimientos, usuarios, roles y permisos, para organizar quién trabaja dónde y qué puede hacer. | Administrador |
| HU06 | Como padre o apoderado, quiero ver a mis hijos y sus controles en el portal familiar, para saber si están al día. | Padre / apoderado |
| HU07 | Como padre o apoderado, quiero presentar un reclamo sobre la atención de mi hijo y adjuntar evidencias, para que el establecimiento lo revise. | Padre / apoderado |
| HU08 | Como personal de salud, quiero revisar y responder los reclamos, para resolver los problemas de atención. | Personal de salud |
| HU09 | Como administrador, quiero ver las sesiones, los dispositivos y las alertas de riesgo, y poder bloquearlos, para proteger las cuentas. | Administrador |
| HU10 | Como administrador, quiero consultar la auditoría de cambios, para saber quién modificó qué información y cuándo. | Administrador |

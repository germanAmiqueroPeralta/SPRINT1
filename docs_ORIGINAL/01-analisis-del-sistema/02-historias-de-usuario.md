# Historias de usuario

| ID | Historia de usuario | Actor |
|---|---|---|
| HU01 | Como coordinador, quiero registrar a un niño con sus datos de padrón y su establecimiento, para poder hacerle seguimiento. | Coordinador |
| HU02 | Como coordinador, quiero ingresar el DNI de un niño o de un padre y que el sistema traiga sus datos de RENIEC, para registrarlos más rápido y sin errores de digitación. | Coordinador |
| HU03 | Como coordinador, quiero registrar a los padres o apoderados y vincularlos con sus hijos, para saber a quién contactar y darles acceso al portal. | Coordinador |
| HU04 | Como coordinador, quiero registrar y corregir los controles CRED de cada niño, para llevar el control de las prestaciones realizadas y pendientes. | Coordinador |
| HU05 | Como administrador general, quiero que las atenciones registradas en la base de datos de la red de salud se carguen automáticamente en SICNA, para que los controles estén al día sin digitarlos dos veces. | Administrador general |
| HU06 | Como administrador general, quiero ver el resultado de cada carga de atenciones (cuántas se aplicaron, cuántas se omitieron y por qué), para corregir los datos que no coincidan. | Administrador general |
| HU07 | Como administrador general, quiero gestionar el catálogo de paquetes y prestaciones por edad, para que los controles sigan la norma vigente. | Administrador general |
| HU08 | Como administrador general, quiero gestionar micro redes, establecimientos, usuarios, roles y permisos, para organizar quién trabaja dónde y qué puede hacer cada uno. | Administrador general |
| HU09 | Como padre o apoderado, quiero ver a mis hijos y sus controles en el portal familiar, para saber si están al día. | Padre / apoderado |
| HU10 | Como padre o apoderado, quiero presentar un reclamo sobre la atención de mi hijo y adjuntar evidencias, para que el establecimiento lo revise. | Padre / apoderado |
| HU11 | Como coordinador, quiero revisar y responder los reclamos, para resolver los problemas de atención. | Coordinador |
| HU12 | Como administrador general, quiero ver las sesiones, los dispositivos y las alertas de riesgo, y poder bloquearlos, para proteger las cuentas. | Administrador general |
| HU13 | Como administrador general, quiero consultar la auditoría de cambios, para saber quién modificó qué información, cuándo y desde dónde. | Administrador general |
